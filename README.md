# A Model of the Observer — for the program that never had one (Penrose program)

Third-party construction, offered to Roger Penrose's program: Penrose has states and reductions (objective reduction, the non-computable mind, conformal cyclic cosmology) but no model of the observer's POSITION. Proposed here: the observer as position zero (the stationary witness), collapse as recognition (the J-positivation, not force), superposition as the indefinite house of the could-have-been, and the descent clause — the observer cannot stay outside because information only exists at the act. Plus the non-computability bridge: 'there is no observation from nowhere' as the metaphysical form of Penrose's mathematics, awaiting Goedel-style rigor.
